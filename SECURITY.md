# Security

## API Keys

This starter sends requests directly from the browser to the configured OpenAI-compatible API base URL. Do not paste a production key into a public or shared browser session.

For public deployments, use a restricted API key when your provider supports it, monitor usage, and rotate the key if it is exposed.

## Reporting

If you find a security issue, please open a GitHub issue without including secrets, tokens, or private account data.
